# Desafio das Três Regiões

Fan game de Pokémon feito no Pokémon Essentials v21.1. Seis campeões refazem Kanto, Johto e Galar, cada um com a sua história, num tom maduro, no estilo de Pokémon Origins.

## Baixar

Vá em **[Releases](../../releases/latest)** e baixe o arquivo `vX.XX_Desafio_Tres_Regioes.zip`.

## Como jogar

1. Extraia o zip numa pasta (botão direito > Extrair tudo).
2. Abra a pasta `Desafio_Tres_Regioes` e rode o `Game.exe`.
3. Só funciona no Windows.

## Controles

- Setas: andar
- C ou Enter: confirmar / falar
- X ou Esc: menu / voltar
- Z: correr
- Q / L: velocidade do jogo (1x, 2x, 3x)

## O que tem na versão atual

- Campanha do Leon: Kanto e Johto completos
- Campanha do Red: Galar, Johto e Kanto completos, do Monte Prata até o Monte Prata
